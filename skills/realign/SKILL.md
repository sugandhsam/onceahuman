# Realign

Reflect the request back in a different frame, then stop. Don't start the work.

Format (short lines, under 120 words):

**Goal:** what should be true when this is done
**Problem:** the pain behind it, described as if to someone who hasn't seen the chat
**I'm assuming:** anything you've inferred that he didn't say
**One pushback:** where the ask and the goal seem to disagree, or "none"
**One question:** only if the answer would change what you build

End with: "Say **go** or correct me." Nothing else — no partial work.

Rules: don't reuse his sentences, mark guesses as guesses, don't manufacture a pushback.
